# שיעורים — משנה תורה: רמב״ם לעם ודפוס וילנא

מאגר קבצים של אפליקציית [שיעורים](https://github.com/ygtotlrl-lab/shiurim), ואין בו קוד. GitHub Pages מגיש אותו, והאפליקציה קוראת ממנו.

כל עמוד — תמונה מוכנה בתקן אחד: PNG שחור-לבן (1 ביט), ברוחב 1600 פיקסלים, קובץ לכל עמוד. הספרים שלמים — כל עמוד פעם אחת, וההלבנה של השיעור הסמוך נעשית בתצוגה, לפי נתונים שבאפליקציה.

- רמב״ם לעם: `hkd/` (ההקדמות) · `mzv/` (ספר המצוות) · `laam1/`–`laam14/` (ארבעה עשר הספרים, המדע עד שופטים). עמוד לכל קובץ (`1.png` ואילך).
- `laam7l/114.png` — עמוד רלה בהלכות תרומות, החסר בסריקת רמב״ם לעם, מושלם מדפוס וילנא — מעמוד 114 של `vil6/` (דף כו).
- `mrh/` — מורה השיעור של קה״ת.
- `vil1/`–`vil12/` — משנה תורה, דפוס וילנא: שנים עשר הכרכים, בסדר של HebrewBooks (58957–58968); עמוד לכל קובץ, והמספר — מספר העמוד בקובץ המקור.

מאגר נפרד מהאפליקציה — האתר מוגבל ל-1GB, והסריקות שוקלות את רובו.

שמות התיקיות: התיקייה הראשית — קוד הספר, 2–4 אותיות לטיניות משמו העברי, ובספר רב־כרכים הקוד ומספר הכרך; השלמה מדפוס אחר — תיקייה משלה: קוד התיקייה שהיא משלימה ואות המקור (`g` מקראות גדולות · `v` ויניציאה · `x` עותק אחר של אותו דפוס · `l` וילנא · `t` תר״ס · `s` סריקה כפולה שפוצלה לשני עמודיה המודפסים); שם הקובץ — מספר העמוד בסריקת המקור.
